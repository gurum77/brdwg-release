# BrDwg AI — 공식 릴리스 채널

BrDwg AI(AI가 매주 스스로 개선하는 CAD)의 설치 파일과 자동 업데이트 피드를 배포하는 저장소입니다. (소스코드 저장소 아님)

- **다운로드**: [최신 설치 파일](https://github.com/gurum77/brdwg-release/releases/latest/download/BrDwgAI-win-Setup.exe) (Windows x64, .NET Framework 4.8)
- **업데이트 소식·의견 보내기**: https://brdwg.vercel.app
- 설치 후 새 버전은 앱이 자동으로 안내합니다.
- 구 BrDwg 제품과는 별개이며 같은 PC에 공존 가능합니다.
