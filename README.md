# BrDwg — 공식 릴리스 채널

BrDwg(범용 CAD)의 설치 파일과 자동 업데이트 피드를 배포하는 저장소입니다. (소스코드 저장소 아님)

- **다운로드**: [최신 설치 파일](https://github.com/gurum77/brdwg-release/releases/latest/download/BrDwg-win-Setup.exe) (Windows x64, .NET Framework 4.8)
- **업데이트 소식·의견 보내기**: https://brdwg.vercel.app
- 설치 후 새 버전은 앱이 자동으로 안내합니다.
